# 🦠 Virus XP
A nostalgic incremental game about feeding a digital virus, making it grow, and spreading across office computers.
## 📖 About

Virus XP is an incremental game set in a world inspired by the Windows XP era. You take care of a small digital virus, feeding it data and helping it grow into something far more powerful.

What begins as a tiny, seemingly harmless program gradually evolves into a thriving digital infestation. Gather MBs, purchase upgrades, unlock new abilities, and expand your influence across the system.

Can you turn a tiny virus into the ultimate digital organism?
